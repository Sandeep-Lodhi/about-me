# 01 — Self Introduction ("Tell me about yourself")

This is the first question in almost every interview. It sets the mood for the whole interview. Practise it until it sounds natural, not memorised.

**Simple formula:** Who I am → Experience summary → Current work → Key strengths → What I want next.

---

## 1. Technical round — 1 minute (use this most often)

> "Good morning. Thank you for this opportunity.
>
> My name is Sandeep Lodhi. I'm a Node.js backend developer with almost 4 years of experience in building REST APIs, backend services and full-stack MERN applications.
>
> Currently I'm working at **Atiya Healthcare** in Delhi. There I build backend systems for a large healthcare call centre — a Hospital Appointment CRM, a WhatsApp automation platform using Exotel APIs, reporting dashboards and automation jobs. I work with Node.js, Express, SQL Server, PostgreSQL, MongoDB and Redis, and I also handle deployment on IIS and Cloudways.
>
> Before this, at **Morpheme Webnexus**, I worked on AWS Lambda serverless backends and CI/CD, and I led an Israeli client project called **TorahAnytime**, where I reviewed and merged PRs and deployed to production.
>
> My strengths are API design, database query optimisation and production debugging. For example, I reduced a slow report query from about 92 seconds to around 300 milliseconds.
>
> Now I'm looking for a backend-focused role where I can work on scalable systems and grow as a Node.js engineer. That's a short summary about me."

## 6. Tips for speaking

| Do | Don't |
|---|---|
| Smile and keep eye contact (look at the camera on video calls). | Don't read from the screen. |
| Speak at a medium speed. Pause between companies. | Don't rush to finish in 20 seconds. |
| Mention 1 number (92 s → 300 ms, 45+ reports). | Don't list 25 technologies in one breath. |
| End with what you want next. | Don't say anything negative about your current company. |
| Keep it 60–90 seconds unless they ask for detail. | Don't tell your full family story in a technical round. |

**After your intro, the interviewer usually picks one thing you said.** So only say things you are ready to explain — Atiya CRM, WhatsApp platform, TorahAnytime, AWS Lambda and query optimisation.

## 7. Common follow-ups right after the intro

**"Which project are you most proud of?"**
> "The Hospital Appointment CRM at Atiya. I replaced an old ASP.NET system with Node.js and React on the same SQL Server databases, with 47 API modules and integrations with the dialer, WhatsApp and SMS. It's used daily by call-centre agents."

**"What is your current role exactly?"**
> "I'm a MERN stack developer, but mostly backend. I own the full lifecycle — requirements, API and database design, development, deployment on IIS and Cloudways, and production support."

**"Why backend and not frontend?"**
> "I enjoy problems where data, performance and reliability matter — like making a 92-second query run in 300 ms. I can do React well, but backend is where I add the most value."
